## Desain Kelas
1. App.java
    - Berisi method main() yang merupakan pintu masuk program. 
    - Mengelola perpindahan layar antara MainMenu, View dan Logic.
    - Mengatur window utama (JFrame) dan controller. 
2. Logic.java
    - Berisi logika permainan yang mencakup game loop, pergerakan, tabrakan, skor, restart, dan audio.
3. MainMenu.java
    - Menampilkan menu awal dengan tombol Start Game dan Exit.
4. View.java
    - Kanvas JPanel untuk merender grafis burung, pipa, skor, dan teks Game Over.
5. Player.java
    - Menyimpan data burung (posisi, ukuran, gambar, dan kecepatan jatuh/lompat).
6. Pipe.java
    - Menyimpan data pipa rintangan (posisi, ukuran, gambar, kecepatan gerak, dan status lewat).
